# Изменения

## 2026-10-06 — замена файла из выбранного diff

- Для входящего MODIFY применяется весь проверенный файл из внешнего target. Несовпадение локального содержимого больше не блокирует проверку; изменения этого же файла заменяются входящей версией.

## 2026-10-06 — выбор файлов и высота просмотра

- Во входящем сравнении можно отметить только нужные файлы; частичное применение не обновляет общий baseline. Панель diff занимает больше доступной высоты окна.


## 2026-10-06 — понятные причины конфликтов и восстановление отсутствующих файлов

- Изменённый или заменённый входящий файл, отсутствующий локально, восстанавливается из проверенного конечного состояния. Сообщение о конфликте теперь объясняет, какой файл и причина остановили применение.


## 2026-10-06 — отсутствующий receiving-файл при переименовании

- Внешнее Git-переименование, у которого отсутствуют оба пути в принимающем репозитории, применяется как новое добавление. Уже занятый путь по-прежнему вызывает конфликт, если его содержимое отличается.

## 2026-10-06 — прямой diff и повторное применение

- Сравнение двух коммитов строит прямой A → B без требования родства; границы и удаления показаны перед применением.
- Уже достигнутое конечное состояние и отсутствующие удаляемые файлы пропускаются; локальные отличия остаются защищены.
- Предпросмотр применения показывает оставшиеся операции; изменение их состава после просмотра останавливает запись.

## 2026-10-06 — выбор входящего diff

- По умолчанию входящие изменения выбираются по внешнему коммиту; добавлены диапазон с явными границами и поиск истории.
- Полное сравнение репозиториев и нулевое состояние доступны отдельными способами.
- Частичный перенос сохраняет независимые внутренние изменения и прежнюю общую точку для исходящих пакетов.

## 2026-10-06 — входящий поток и обзор проверки данных

- КБ-проверка и маскирование оставлены только для исходящих пакетов. Получение изменений проходит напрямую к проверке применения.
- Первый входящий diff определяется по общему коммиту веток вместо сравнения с пустым состоянием.
- Возвращён список файлов и срабатываний с поиском, индивидуальными галочками и массовым сохранением значений.

## 1.0.0 — 2026-10-05

- По запросу пользователя Security Scan показывает исходный найденный текст с подсветкой вместо маскирования; экспортируемые bytes не меняются.

- Security Scan сгруппирован по файлам: заметное имя и полный путь, действия на уровне файла, компактные строки с причиной/кодом/решением и общая раскрываемая справка.

- Security Scan показывает masked контекст с подсветкой и фактическую строку файла; «Открыть источник» ведёт к файлу/коммиту/строке. Исключение обновляет подготовленный пакет без повторного Git I/O и сохраняет прежний preview при ошибке записи.

- Переработана статистика экспорта: главный счётчик показывает файлы в Diff/Snapshot, общий размер проекта вынесен отдельно; добавлены цветные операции, шкала состава изменений, явные commits «от → до» и блок размера/частей пакета.

- Исправлено перекрытие полей в колонке рядом с diff: поля и кнопки формы располагаются вертикально, длинные значения больше не расширяют соседние колонки.

- Добавлена правая панель автоматического сравнения в настройках: дерево каталогов, поиск и построчный diff выбранного файла с номерами строк, подсветкой и маскированием чувствительных значений только в preview.

- Добавлен Diff между независимо выбранными исходным и целевым коммитами разных веток; выбор сохраняется по контурам. Settings v3 мигрирует v1/v2. Импорт поддерживает исходный commit из принимающего Git без предварительной синхронизации, с проверкой файлов.

- Ветки выбираются из выпадающего списка; ветки и история загружаются при открытии настроек и после ввода источника, коммиты обновляются при выборе ветки. Убран предел 256 коммитов; повторный выбор той же ветки сохраняет SHA.

- Исправлены выравнивание карточек выбора контура и высота полей формы. Добавлены крестики закрытия модалок; заголовок и кнопки остаются видимыми при прокрутке формы.

- Добавлены Electron desktop UI, Internal/Global, Profiles/Import/Settings и типизированный preload.
- Добавлен выбор ветки и конкретного commit отдельно для Internal/Global, включая списки веток/истории и ручной полный SHA.
- Реализованы committed Local Git и Global Remote Git через системный Git, exclusions и видимые статусы working tree.
- Добавлены Full Snapshot / Diff, lossless encodings, проверка integrity, chunking и pending подтверждение передачи.
- Добавлены Import preview, baseline preflight, backup, проверка результатов, rollback и startup recovery.
- Добавлен локальный Security Scan с маскированными findings, исключениями, открытием источника, span replacement и явным override secrets.
- Добавлены документация и команды dev / production build для macOS и Windows.

- Ускорена работа с Git: загруженные ветки и история доступны из локального кэша, проверка обновлений выполняется в фоне. Preview читает только выбранный файл; экспорт читает blobs пакетно.

- Security Scan показывает причины блокировки экспорта. Добавлены массовое принятие оставшихся срабатываний и явная замена выбранного совпадения на `***` только в пакете, с сохранением файла.

- Экспорт переведён на открытый transport v2: literal UTF-8 текст/diff в Markdown, бинарные файлы отдельными исходными вложениями. Base64/Brotli в новом экспорте отсутствуют; импорт v1 сохранён. Счётчик учитывает все переносимые файлы.

- Обновлён интерфейс: графитовая и светлая темы, SVG-иконки, короткие анимации и reduced-motion. Профили в sidebar, Scan с выбором файла, закреплённые действия экспорта. Diff получил режим рядом, базовую подсветку синтаксиса и регулируемую ширину дерева.

- Выбор исходной/целевой ветки: поиск без учёта регистра и список из 8 видимых строк с собственной прокруткой вместо macOS popup select.

- Исправлена потеря фокуса при вводе exclusions и других полей профиля: preview больше не отключает форму, его запросы выполняются последовательно.

## 2026-10-06

- Repository Profile получает роль Internal/External; глобальные среды и ручные SHA/Snapshot/Diff selectors убраны из основного workflow.
- Два направления синхронизации используют общую immutable sync state и сохраняют независимые изменения принимающей стороны; конфликт останавливается до записи.
- Desktop redesign: верхняя панель, repositories, центральный diff и отдельный Security Review; foundation/feature components выделены из App.
- Transport v3 выпускает только .md, включая binary и multipart; compact по умолчанию, readable опционально. Старые v1/v2 пакеты читаются.
- Security values маскируются в Main; замена только в пакете удалена. Исправление исходника требует обычного Git commit.
- Settings v4 мигрирует старые profiles с сохранением исходного JSON; прежние baselines требуют первичной синхронизации в новой модели.

- Подпись исходящего действия заменена на «Подготовить пакет изменений»; подсказки используют нейтральную терминологию передачи пакета.

- Все тексты интерфейса и пользовательские сообщения отредактированы на русском: понятные действия, роли «Внутренний / внешний», явное включение найденных данных в пакет и инструкции при ошибках. README использует те же названия.

- Выбор локальной и внешней ветки получил раскрываемый список с поиском, прокруткой и статусами загрузки/ошибки. Ошибка Git больше не выглядит как пустой список; доступна повторная попытка.

- Первое получение сравнивает локальную и внешнюю ветки независимо от общей Git-истории; одинаковые файлы больше не считаются новыми. Удаления локальных файлов показаны явно.
- Ошибка проверки применения видна рядом с кнопкой; доступно обновление сравнения после отказа.

- Добавлен фильтр отступов и переносов строк в сравнении со счётчиками показанных и скрытых файлов; содержимое переноса не меняется.

- Грубый фильтр всех пробелов заменён тремя независимыми: CRLF/LF, края строк, пустые строки. Добавлены отдельные счётчики, штриховка вставок и выделение изменённых слов в просмотре рядом.

- Добавлен режим сравнения как compare-projects: сворачивание пробельных последовательностей со счётчиком скрытых файлов.
