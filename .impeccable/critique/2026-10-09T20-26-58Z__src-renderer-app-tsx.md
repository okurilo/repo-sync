## Приоритетные замечания

### 1. [P1] Длительное чтение Git нельзя отменить

SyncWorkflow.tsx:27 отключает закрытие при locked, AppShell блокирует навигацию. Git runner ограничен 120 секундами, публичной отмены текущей операции нет. При зависшем источнике пользователь ждёт timeout либо закрывает приложение.

Минимальное направление: безопасная отмена read-only чтения/сравнения через существующий Git runner; не разблокировать выход во время Apply без корректного окончания или отката. Произвольный процент прогресса не нужен. Команда: impeccable harden.

### 2. [P2] Вторичные фильтры перегружают сравнение

Comparison.tsx:120–122 одновременно показывает четыре фильтра, их счётчики, пояснения, поиск, массовый выбор и переключатели вида. Задача выбора переносимых файлов конкурирует с настройкой отображения. Имя compare-projects отсылает к внешней утилите.

Минимальное направление: раскрываемые «Настройки просмотра», видимый индикатор активных фильтров и числа выбранных скрытых файлов. Сохранить текущий контракт: фильтры не меняют выбор и payload. Команда: impeccable distill.

### 3. [P2] В режиме «Рядом» недостаточно доступных обозначений изменений

Comparison.tsx:122 использует цвет строк и подсветку фрагментов, без текстового типа добавления/удаления; переключатели используют $active без aria-pressed. «До/После» и штриховка отсутствующей стороны помогают визуально, но программно не объясняют тип каждой изменённой строки.

Минимальное направление: доступные обозначения добавленных/удалённых строк и состояния переключателей. Полный VoiceOver/NVDA проход нужен отдельно; нарушение конкретного стандарта этим разбором не сертифицируется. Команда: impeccable audit.

### 4. [P2] Новый профиль предлагает удалить ещё не созданный объект

Визуально подтверждено: форма «Добавить репозиторий» показывает «Сохранить / Отмена / Удалить профиль». RepositorySettings.tsx:27 выводит удаление без условия; для несохранённого draft App.tsx:156 просто закрывает форму.

Минимальное направление: показывать удаление только для существующего профиля. Удаление сохранённого профиля уже имеет native confirmation в main.ts; замечание не о потере файлов. Команда: impeccable clarify.

### 5. [P2] Карточки повторяют неизвестное состояние

Repositories.tsx:12,18 одновременно сообщает «состояние Git не проверено», «Изменения: не проверено» и «Ещё не выполнялась», затем повторяет общую инструкцию. Повторение занимает место, но не даёт нового следующего шага.

Минимальное направление: один нейтральный статус и конкретное действие; дату показывать при наличии истории. Не добавлять фоновые проверки ради заполнения карточки. Команда: impeccable distill.
