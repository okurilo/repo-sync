# RepoSync

Локальное desktop-приложение для переноса состояния Git между Internal и Global через Markdown-пакеты. Пакеты переносит пользователь. Git history и `.git` не передаются.

## Запуск из исходников

Нужны Node.js **22.14+** и системный Git в `PATH`. Для Remote Git настройте SSH Agent или Git Credential Manager вне RepoSync.

```sh
npm install
npm run dev
```

При первом запуске выберите Internal или Global. Создайте профиль, укажите repository, загрузите ветки и выберите commit. Можно оставить последний commit ветки или указать конкретный из списка / полный SHA. В Settings выберите папку экспорта.

1. Для первого переноса выберите Full Snapshot → Compare и Security Scan.
2. Проверьте список файлов и findings. Исключите чувствительные файлы, исправьте их в источнике или явно разрешите экспорт.
3. Создайте пакет. Перенесите **все** `.md` и бинарные вложения, сохранив их имена.
4. На принимающей стороне создайте профиль и выберите Import, любую часть и локальный target Git repository. Для первого Snapshot используйте пустой repository, созданный командой `git init`.
5. Выполните Analyse package, проверьте preview и примените с backup.
6. На отправляющей стороне нажмите «Пакет успешно перенесён». Следующий пакет можно создать как Diff.

Экспорт использует **committed state выбранной ветки**, а не текущие незакоммиченные файлы. Staged / unstaged / untracked показываются отдельно. Исправления Security Scan меняют working tree: их нужно самостоятельно закоммитить перед новым committed export.

В Global профиль может использовать Remote Git вместо Local Git. Ветка и конкретный commit выбираются отдельно для Internal и Global. В настройках можно включить «Сравнить два выбранных коммита» и независимо выбрать исходную и целевую ветки/коммиты, включая последний коммит каждой ветки. Diff сравнивает их конечные состояния напрямую (без merge-base), поэтому работает и между разошедшимися ветками, в обратном направлении и без предыдущей синхронизации. Без этого выбора исходным состоянием Diff служит последнее подтверждённое; если corporate commit отсутствует в выбранном Git source, используются файлы локального repository, в который этот профиль импортировал пакет.

## Production build

```sh
npm run build
npm start
```

Установочные пакеты для macOS собираются на macOS:

```sh
npm run dist:mac
```

Windows NSIS / ZIP собираются на Windows:

```sh
npm run dist:win
```

Результат находится в `release/`. Для распространения с доверенной подписью отдельно настройте сертификаты electron-builder. Приложение не публикует сборки и не обновляется автоматически.

Security Scan — локальная эвристическая проверка. Она не гарантирует обнаружение всех конфиденциальных данных. Проверяйте содержимое перед передачей.

Для импорта Diff принимающие файлы должны соответствовать исходному состоянию. Если профиль ещё не синхронизирован, исходный коммит должен присутствовать в принимающем Git, а exclusions должны совпадать. Если коммита там нет, сначала перенесите его Full Snapshot. Произвольное сравнение коммитов не включает вручную возвращённые ignored-файлы.

В настройках профиля справа доступен автоматический предпросмотр сравнения: дерево изменённых файлов, поиск по пути и построчный diff с номерами строк. Без исходного коммита используется last sync, а при его отсутствии — просмотр полного Snapshot. Preview не сохраняет настройки и не создаёт пакет. Чувствительные значения маскируются только на экране; бинарные и файлы больше 128 KB показываются без кода.

В Security Scan можно принять оставшиеся срабатывания одной кнопкой, исключить файл либо заменить выбранное значение на `***` только в экспортируемом пакете. Исходный репозиторий при такой замене не меняется. Причины блокировки показаны рядом с кнопкой экспорта; для оставленных secrets требуется отдельное разрешение.

Экспорт v2 открыт для просмотра: `.md` содержит читаемый JSON-манифест и исходный текст/diff, бинарные вложения сохраняются отдельными файлами в исходном формате. Сжатия, Base64 и шифрования в новом экспорте нет. На принимающей стороне нужна обновлённая версия RepoSync; старые пакеты v1 по-прежнему импортируются.
